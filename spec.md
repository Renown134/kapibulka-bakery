# Спецификация

## Назначение и сценарий

Локальная страница «булки дня» мини-пекарни «Капибулка».

1. Посетитель видит название и короткое обещание.
2. Читает карточку «Коричная капибара» с коротким описанием.
3. Нажимает «Выбрать булку дня» и видит локальное подтверждение «Вы выбрали: Коричная капибара» без перехода и перезагрузки.
4. Только в отдельной интерактивной итерации получает кнопку «Сбросить выбор»: она убирает подтверждение и возвращает исходное состояние.

Выбор хранится только в памяти страницы: после перезагрузки исходное состояние. Повторное нажатие выбора не создаёт дубликаты подтверждения.

## Состав страницы

- Шапка: название «Капибулка».
- Первый экран: короткое обещание «Тёплая булка для уютного дня».
- Заметная карточка предложения: «Коричная капибара», короткое описание и кнопка выбора.
- Три коротких шага: «Познакомьтесь с булкой», «Выберите булку дня», «Получите подтверждение».

## Визуальное направление

По отдельному запросу пользователя в ветке `design/ocean-turtle` применено морское оформление: светлый фон морской пены, глубокий синий основной цвет, бирюзовый акцент и песочные детали. Вместо булочки — нарисованная морская черепаха, встроенная в HTML как data URI без внешнего файла или сетевого запроса. Название, тексты и сценарий пекарни сохранены. Крупная читаемая типографика, свободные отступы и визуально выделенная карточка предложения. На узком экране текст и кнопки не обрезаются, горизонтальной прокрутки нет. Кнопки доступны с клавиатуры и имеют видимый фокус; подтверждение доступно для вспомогательных технологий.

## Наблюдаемые критерии готовности

- `index.html` открывается напрямую с диска без установки и интернета; все четыре части страницы видны.
- Название, обещание, название булки и надпись кнопки соответствуют требованиям.
- Нажатие кнопки показывает одно подтверждение на той же странице; ошибок в консоли нет.
- После шага 3 плана сброс скрывает подтверждение, восстанавливает исходное состояние и позволяет снова выбрать булку.
- В браузере проверены широкий и узкий экран, читаемость, отсутствие обрезаний и управление кнопками с клавиатуры.
- Вся реализация находится в одном `index.html`; внешние ресурсы и сетевые запросы отсутствуют.

## Границы

Только встроенные HTML, CSS и простой JavaScript в одном самодостаточном `index.html`. Без фреймворка, серверной части, базы данных, внешних зависимостей (включая шрифты и изображения), сетевых запросов, реальных данных и секретов. Все тексты демонстрационные.

Запрещено добавлять функции вне описанного сценария: каталог, корзину, оплату, формы заказа, регистрацию, доставку, аналитику или сохранение выбора между загрузками. Сброс не входит в первую версию и выполняется отдельной итерацией.
