# План и ручная проверка

Текущая задача: добавить встроенный Node.js-сервер и API в существующий проект, подготовить Amvera. Это отдельный согласованный объём после визуальной и интерактивной итераций. AGENTS.md не изменять, команды Git не запускать. Деплой не выполнять в рамках подготовки файлов.

## Реализация

- Сервер, package.json и amvera.yaml добавлены без зависимостей.
- Существующий index.html обновлён: кремово-зелёная палитра с коралловыми кнопками, загрузка меню, выбор, сброс и серверное время.
- README.md и spec.md приведены к новой архитектуре.

## Ручная приёмка (ожидает проверки)

1. [ ] Выполнить `npm run build` — синтаксис server.js проверен без установки пакетов. Выполнить `npm start` — после успешного запуска появляется строка с 0.0.0.0 и портом 3000.
2. [ ] Открыть http://localhost:3000 и /index.html — оба адреса показывают существующий интерфейс. Видны булка дня, два круассана из API, три шага и учебная оговорка.
3. [ ] Выбрать по очереди каждую из трёх позиций — текст подтверждает правильное название, выделена ровно одна карточка, её кнопка скрыта, сброс виден. В Network — POST /api/selection с правильным id и ответ 200.
4. [ ] Нажать сброс — POST /api/reset, сообщение о сбросе, выделение исчезает, кнопки выбора возвращаются, сброс скрывается. Повторить выбор и сброс с клавиатуры.
5. [ ] Нажать «Проверить пекарню» — GET /api/status и видимое время сервера. Повторить позже — время обновилось. При ошибке сети виден понятный текст, ложного успеха нет.
6. [ ] Перезагрузить страницу — выбор отсутствует. Открыть вторую вкладку — в ней нет чужого выбора. При ошибке сброса текущий выбор сохраняется в интерфейсе.
7. [ ] Проверить узкое и широкое окно: читаемые тексты, нет горизонтальной прокрутки; Tab показывает фокус. Внешних запросов и хранилища браузера нет.
8. [ ] Проверить API отдельно: неизвестный id и сломанный JSON дают 400; неподходящий Content-Type — 415; большое тело — 413; неизвестные URL и неподдерживаемые методы — 404. GET /server.js и /package.json также дают 404.
9. [ ] В Amvera загрузить восемь корневых файлов, проверить конфигурацию Node.js/npm/18, сборку npm run build, запуск npm run start и containerPort 3000. Без Docker, Volume, Variables и CLI. Открыть домен приложения и повторить меню → выбор → сброс → статус. Подтвердить успешность по журналам и браузеру, а не по наличию конфигурационного файла.

## Выполненные проверки

- `npm run build` прошёл; `npm start` успешно запустил сервер на 0.0.0.0:3000. Проверка выполнена установленным npm по полному пути, поскольку в рабочем окружении npm отсутствует в PATH.
- GET / и /index.html вернули точное содержимое существующего файла. Проверены меню, подтверждения всех трёх позиций, сброс, серверное время и ответы 400/404/413/415.
- Проверено PORT=0: строка запуска содержит фактически выделенный порт. Неверный и занятый порты завершают запуск с ошибкой без строки успеха.
- Логика браузерного скрипта проверена вне браузера с моделью элементов и реальным API: загрузка меню, выбор, единственное выделение, переключение кнопок и фокуса, сброс, время, ошибки сети без ложного успеха. Это не проверка внешнего вида в браузере.
- Временные серверы проверки остановлены. В корне ровно восемь требуемых файлов; дополнительные файлы тестов и зависимостей не создавались. AGENTS.md не изменялся, команды Git не запускались.

Ручная приёмка в браузере и деплой Amvera пока не подтверждены.
