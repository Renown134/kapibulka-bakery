# План реализации

Создана первая версия `index.html` по шагу 1. Ожидается открытие файла пользователем и ручная проверка в браузере; шаг пока не принят и оставлен без отметки. Шаги 2–4 не выполнялись. Каждый шаг — отдельная небольшая задача в пределах `spec.md`.

1. [ ] **Первая версия `index.html` с выбором булки дня.** Создать шапку, первый экран, карточку «Коричная капибара» и три коротких шага. Добавить кнопку «Выбрать булку дня» и локальное подтверждение. Применить базовое визуальное направление. Проверка: открыть файл напрямую, прочитать страницу и нажать кнопку — появляется одно подтверждение без перехода. Сброс пока не добавлять.
2. [ ] **Отдельная визуальная итерация после проверки в браузере.** Осмотреть первую версию на широком и узком экране, затем уточнить типографику, отступы, цвета и акцент карточки по наблюдениям. Проверка: повторно осмотреть оба размера — текст читается, кнопка заметна, обрезаний и горизонтальной прокрутки нет; выбор продолжает работать.
3. [ ] **Отдельная интерактивная итерация — сброс выбора.** После выбора показывать кнопку «Сбросить выбор», возвращающую страницу в исходное состояние. Проверка: выбрать → увидеть подтверждение → сбросить → увидеть исходное состояние → выбрать повторно; проверить кнопки с клавиатуры.
4. [ ] **Финальная сверка с документами и ручной сценарий.** Сверить состав, оформление и ограничения с `README.md`, `spec.md`, `AGENTS.md`. Проверка: открыть файл, увидеть название и обещание, прочитать карточку, выбрать, увидеть подтверждение, сбросить и повторить выбор. Перезагрузить — исходное состояние. Проверить отсутствие ошибок в консоли, внешних ресурсов и сетевых запросов; зафиксировать результат ручной проверки.
