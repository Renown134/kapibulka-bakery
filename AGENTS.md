# Правила работы

- Перед каждой задачей сначала читать `README.md`, `spec.md` и `PLAN.md`.
- Менять только согласованный скоуп текущей задачи. Не добавлять функции вне сценария и не объединять отдельные итерации плана.
- Реализацию держать в одном самодостаточном `index.html` со встроенными HTML, CSS и простым JavaScript.
- Не использовать фреймворки, серверную часть, базу данных, внешние зависимости, сетевые запросы, реальные данные или секреты.
- После каждой задачи кратко описывать результат и предлагать наблюдаемую проверку: конкретное действие и ожидаемый видимый результат. Различать выполненную проверку и предложенную.
- Отмечать завершённые шаги в `PLAN.md` только после выполнения; не объявлять непроверенное проверенным.
- Текущая задача — только четыре документа: `README.md`, `spec.md`, `AGENTS.md`, `PLAN.md`. Создание `index.html` начинается отдельной задачей.
