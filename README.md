# Капибулка — булки дня

Учебный сайт мини-пекарни: булка «Коричная капибара», меню из двух круассанов, выбор, сброс и проверка времени сервера. Кремовый фон, тёмно-зелёная карточка, коралловые кнопки. Существующая встроенная иллюстрация черепахи сохранена.

## Локальный запуск

Нужны Node.js и npm. В Amvera используется Node.js 18. Внешних пакетов нет, установка зависимостей не требуется.

```sh
npm run build
npm start
```

`build` выполняет только `node --check server.js`. Откройте http://localhost:3000. Сервер отдаёт существующий `index.html` и API с того же адреса. Открытие HTML двойным щелчком позволяет увидеть оформление, но API требует запущенного сервера.

Сервер слушает `0.0.0.0`, использует `process.env.PORT` или локальный порт 3000. Строка запуска появляется только после успешного открытия порта и содержит фактически выбранный порт. Для остановки нажмите Ctrl+C.

## Публикация в Amvera

В корне приложения должны находиться `AGENTS.md`, `README.md`, `PLAN.md`, `spec.md`, `index.html`, `package.json`, `server.js` и `amvera.yaml`. Загрузите эти файлы в раздел кода приложения Amvera или подключите репозиторий с этой версией. Корневой каталог — корень проекта, а не имя ветки.

Конфигурация `amvera.yaml` задаёт Node.js, npm и версию 18, проверку `npm run build`, запуск `npm run start` и порт 3000. Дополнительные пакеты, команды CLI, Docker, постоянное хранилище и пользовательские переменные не нужны. После сборки и запуска откройте адрес приложения из раздела доменов Amvera, проверьте страницу и `/api/status`.

Публикация в этой задаче не выполнялась. Формат конфигурации: [документация Amvera](https://docs.amvera.ru/applications/environments/nodejs-server.html).

## Границы

Только встроенные `node:http`, `node:fs`, `node:path`. CSS, браузерный JavaScript и изображение находятся в существующем `index.html`, отдельных статических папок нет. Запросы браузера идут только к API этого сайта. Сервер не сохраняет выбор: ни файлов записи, ни базы данных, ни изменяемого состояния выбора. В браузере выбор живёт только до перезагрузки, без хранилища. Нет оплаты, реального заказа, авторизации, секретов и запросов к внешним сервисам.

Маршруты и критерии — в `spec.md`, ручные проверки — в `PLAN.md`. `AGENTS.md` сохранён без изменений; новый явно согласованный объём работ описан в этих документах.
