# Капибулка — булки дня

Одна локальная страница мини-пекарни «Капибулка»: посетитель знакомится с булкой дня «Коричная капибара» и выбирает её, получая подтверждение на странице.

## Локальное открытие

Открыть `index.html` двойным щелчком в браузере. Установка, сборка, сервер и интернет не нужны. Первая версия создана; ожидается ручная проверка пользователем в браузере.

## Состав и направление

Шапка с названием, первый экран с коротким обещанием, заметная карточка булки дня и блок из трёх коротких шагов. В ветке `design/ocean-turtle` — морское оформление: светлый фон морской пены, глубокая синяя карточка, бирюзовые кнопки, песочные детали и нарисованная черепаха. Изображение встроено в `index.html`, отдельный файл не нужен. Выбор и сброс работают локально.

## Рамки работы

Вся страница — один самодостаточный `index.html` со встроенными HTML, CSS и простым JavaScript. Без фреймворков, серверной части, базы данных, внешних зависимостей, сетевых запросов, реальных данных и секретов. Функции вне сценария запрещены.

Точные требования и проверки — в `spec.md`, порядок итераций — в `PLAN.md`, правила работы — в `AGENTS.md`.
